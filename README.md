__What the code does:__
1) Imports the data from the CSV file
2) Prints how many crabs there are for each sex (M,F,I)
3) Prints how many crabs there are for each age
4) Prints the stats of the most similar and most different crabs, and how similar/different they are. This calculation is based on their length, diameter, and height. For example, a crab with values length 1, diameter 1, height 1 would be similar to a crab of length 1.1, diameter 1.1, height 1.1. Similarly, a crab of length 1, diameter 1, height 1 would be very different than a crab of length 100, diameter 100, height 100
